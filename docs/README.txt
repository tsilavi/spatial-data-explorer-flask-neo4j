spatialdataexplorer
A web-based search system that renders spatial and attribute exploring on spatial data sources that metadata are indexed in details for them.
In this system, the existing data sources are coded in detail and the spatial area to 
which the data belongs is also recorded in detail. 
The user of this system can find a list of all existing data that matches the entered 
title or is related to the requested location by registering the titles he wants or 
specifying a location and introduce it to the user.
In the development of this system, a graph database management system has been used 
as a database that stores the metadata of the existing data and the Flask environment has been used
