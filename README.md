# spatialdataexplorer
A web-based search system that enables spatial and descriptive exploration of spatial data with comprehensive metadata indexing.

In this system, the existing data sources are indexed in detail and the spatial area to which the data belongs is also precisely recorded. 
The user of this system can find a list of all existing data that matches the entered keywords or is related to the requested location by registering the names or specifying a location in desired region.
In the development of this system, the neo4j graph database management system has been used to stores the metadata of the existing data sources and the Flask framework has been used to back-end implementing.

The backend is powered by the Flask framework.
